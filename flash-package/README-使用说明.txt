# 小智 · 抽纸唤醒固件（v9.9.9-tissue）

## 这是什么
官方 xiaozhi-esp32 固件（最新 main，2026-10-31）+ 一个新增功能：
**连续抽几张纸的声音 → 自动唤醒小智**（与喊"你好小智"完全等价）。

官方全部功能原样保留：语音唤醒词、对话、MCP 控设备、通知、OTA 检查。
新增功能只在待机时监听，说话/播放时不工作。

## 烧录步骤（Windows）
1. 板子用 USB 线连接电脑（双 Type-C 板子，任一口都行，优先标 USB 的口）
2. 解压本包，双击 `flash.bat`
3. 等进度条走完，拔插 USB 重启

首次开机与官方流程完全一致：屏幕提示激活/连网 → 微信扫码或按提示操作。

## 万一烧录失败
- 设备管理器看不到 COM 口 → 装 CH343 驱动（https://www.wch.cn/downloads/CH343SER_ZIP.html）
- 进度条卡住 → 按住板上 BOOT 键再点一次烧录
- 其他报错 → 把黑窗口里的文字截图发我

## 万一麦克风没声（板型配置不符的兜底方案）
本包按"面包板新版 + 0.96 寸 OLED 128x64"编译。若喇叭响但麦克风不收音，
说明这套板子的麦克风接线不是标准面包板引脚——告诉我，我按你的接线重出一包。

## 抽纸唤醒怎么调
固件内置参数（当前默认：约 3 秒连续抽纸声触发 / 触发后 10 秒冷却）：
- 太灵敏 → 我把阈值/连窗参数调高重出包
- 太迟钝 → 调低
改参数只需重编译，你重新烧一次即可，不用重新录音。

## 技术信息
- 基线：xiaozhi-esp32 main@addb1ed（2026-10-31）
- 新增文件：main/audio/sound_events/（检测器 + 30KB int8 模型 + mel 滤波器组）
- 模型：你 10-31 录音训练，固件同款前端验证：正样本中位 0.996 / 负样本 0.000
- 版本号 9.9.9：防止官方 OTA 推送覆盖二开固件（OTA 检查仍正常进行）
- 所有改动 diff 约 60 行 + 7 个新文件，随时可搬迁到官方新版本
